# Daily development log

This folder holds **per-day** notes for work tied to **OpenSpec apply** (and similar maintainer workflows).

## Language

All content in `docs/daily/*.md` — including headings, bullets, and explanations — **must be written in English only**, now and for every future entry.

Use one file per calendar day: `yyyy-mm-dd.md`. The top heading should be:

`# Daily log — yyyy-mm-dd`
